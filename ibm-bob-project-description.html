What is IBM Bob?

"IBM Bob is an AI SDLC (Software Development Lifecycle) partner that augments your existing workflows and helps you understand, plan, improve, and work confidently with real codebases — while offering proactive insights that keep you in control at every step."

Bob is an agentic IDE (Integrated Development Environment) built by IBM. Unlike a simple chatbot or autocomplete tool, Bob is a full AI agent — it can read files, write code, run terminal commands, browse the web, and connect to external services. You interact with it through a natural-language chat interface, and Bob translates your instructions into real, reviewable actions on your codebase.

Why Was Bob Built?

Modern software development is complex: developers must simultaneously understand legacy codebases, plan new features, write and review code, run tests, fix bugs, and write documentation — often under time pressure. Traditional tools address individual steps in isolation.

IBM built Bob to be a unified AI partner across the entire SDLC — from the first design conversation to deployed, tested, and documented code. The core motivation:

  • Reduce friction at every step of software development
  • Help developers understand unfamiliar codebases faster
  • Automate repetitive tasks (boilerplate, docs, tests) without losing developer control
  • Bring AI assistance that is grounded in real code, not generic examples
  • Keep the developer in charge — Bob proposes, you approve

How Does Bob Work?

Bob uses Large Language Models (LLMs) to understand your requests and route them to specialized tools. It automatically selects the right model for each task based on complexity, context size, and cost-efficiency — you never need to configure this manually.

You Chat
Natural language instructions in the chat interface
Bob Plans
Decomposes your request into steps and selects the right tools
Bob Acts
Reads files, writes code, runs commands, calls APIs
You Review
Inspect proposed changes before approving them
Iterate
Refine, ask follow-ups, or switch modes as needed

Three Built-in Modes

Bob adapts its behaviour based on the mode you're working in. Each mode has a focused purpose and a specific set of tools.

Privacy & Data Policy

IBM does not use your prompts or code for model training. Prompts are temporarily cached only to improve inference performance. Bob collects optional, anonymous telemetry (actions taken, tool usage, conversation events) to improve the product — it never collects code snippets, chat sessions, or personal payload data.

Bob in This Project — Salary Prediction

In this session, Bob was used as a hands-on AI SDLC partner to build a complete Salary Prediction ML model from scratch:

  • Explored and understood the raw dataset (Salary Data.csv, 375 rows)
  • Installed required Python libraries (scikit-learn, matplotlib, seaborn)
  • Designed and wrote the full ML pipeline — imputation, encoding, scaling, train/test split
  • Trained and compared 3 regression algorithms (Ridge, Random Forest, Gradient Boosting)
  • Evaluated models with MAE, RMSE, R², and 5-fold cross-validation
  • Identified the best model (Ridge Regression, R² = 0.91) and explained why it won
  • Generated feature importance analysis and sample salary predictions
  • Produced a visualisation plot and this shareable description report

All of this was accomplished through natural-language conversation — no manual file browsing, no copy-pasting of code, no switching between tools.
